# Diagrams

Architecture and sequence diagrams.

- `architecture.puml` / `.mmd` — system overview (see docs/architecture.md).
- `data-flow.puml` — end-to-end outreach data flow.
- `sequence-*.puml` — key user journeys.

Keep diagrams as source (PlantUML `.puml` or Mermaid `.mmd`) so they stay
editable and diffable; commit rendered PNGs alongside if shared with non-devs.
